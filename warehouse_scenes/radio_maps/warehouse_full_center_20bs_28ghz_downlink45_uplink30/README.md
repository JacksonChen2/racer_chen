# Warehouse Full 中心区域 20 个 BS 候选点

候选点采用中心区域的 5×4 规则网格：`x={-16,-13,-10,-7,-4}`、
`y={11,14,17,20}`，射频高度固定为 `z=7.248835537456077 m`。

`warehouse_full_20bs_uplink_downlink_overviews.pdf` 是唯一的图片汇总文件，共 20
页；每个候选点占一页，左侧是五个 UAV 高度层（0.75、1.5、3、5、7.5 m）的
下行总览，右侧是对应的上行总览。各候选目录仅保留压缩 NPZ 数据和统计 JSON。
PHY 为 28 GHz/100 MHz，下行发射功率 45 dBm，上行发射功率 30 dBm；地图
分辨率 0.5 m。

`candidate_ranking.csv` 按五个高度层合并后的上行接收功率高于 -120 dBm 的
网格覆盖率降序排列，再以上行平均接收功率作为并列排序项。该指标下最优点为
`bs_08=(-10,14,7.248835537456077) m`。
