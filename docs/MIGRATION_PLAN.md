# RACER ROS 2 Python migration

## Scope

This branch ports RACER from ROS 1/catkin/C++ to ROS 2 Humble/colcon/Python
3.10. The reference implementation remains in `swarm_exploration/` and
`uav_simulator/`, but both trees contain `COLCON_IGNORE` and are not part of
the ROS 2 build. The active workspace is `ros2_ws/`.

## Invariants

- Exploration, frontier extraction, hierarchical partitioning, task exchange,
  graph search, trajectory generation, and finite-state transitions retain
  their original data flow and parameter meanings.
- ROS callbacks are adapters. Algorithms live in `racer_core` and do not
  import ROS.
- All active runtime nodes use `rclpy`.
- Custom interfaces are generated by the only `ament_cmake` package,
  `racer_interfaces`.
- Isaac Sim runs in its own Python environment and communicates only through
  the ROS 2 Bridge.
- The original simulator is replaced at the simulation boundary by Isaac Sim.
  Dynamics and control adapters consumed by RACER remain Python.

## Packages

| Package | Build type | Responsibility |
| --- | --- | --- |
| `racer_interfaces` | `ament_cmake` | Custom messages and TSP services |
| `racer_core` | `ament_python` | ROS-independent RACER algorithms |
| `racer_ros` | `ament_python` | `rclpy` nodes and message conversion |
| `racer_bringup` | `ament_python` | Launch, parameters, and RViz2 |
| `racer_isaac` | `ament_python` | Isaac Sim ROS 2 Bridge contracts |

## Status convention

- `IMPLEMENTED`: source migration is present.
- `NOT_RUN`: intentionally not built or executed in this Windows checkout.
- `TARGET_REQUIRED`: requires Ubuntu 22.04, ROS 2 Humble, or Isaac Sim 5.1.

This branch intentionally records runtime/build verification as `NOT_RUN`
until it is executed in the target environment.
